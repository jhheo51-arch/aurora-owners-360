# v4.3 설계 초안 — 오로라 AI 상담(AICX) 고도화: 단순 문의는 AI가 끝낸다

> 상태: **✅ 구현 완료 (2026-10-15, 태그 `v4.3`, 결과는 PRD §20-12)**. 아래는 설계 당시 기록. 메인 세션이 시연 영상을 녹화하는 동안 AICX 코드·org를 바꾸지 않으려고 이 파일만 새로 만들었다. 구현은 녹화가 끝난 뒤 메인 세션에서 한다(v4.2와 순서는 결정 D7).
> 사용자 확정(2026-10-15): ① 이 문서까지 사이드 챗, 구현은 메인 ② 정기점검 주기는 **차량 모델별 필드** ③ 고객 이력 규칙(R2~R5)은 **정보 조회 질문에는 적용하지 않음**.

## 1. 문제 — 왜 거의 다 상담사로 연결되나
사용자 테스트: "정기점검 언제예요?" 같은 단순 질문도 상담사로 연결됨. 코드(`AicxRoutingService.evaluate`) 확인 결과 원인 두 가지.

1. **질문과 무관한 고객 이력 규칙이 무조건 연결시킨다.** R1~R7 중 하나라도 걸리면 `HANDOFF`인데, R2(90일 VOC 2건·같은 유형 진행 중)·R3(이관·기한 위반·보상 반려 이력)·R4(플래티넘·위험 높음)·R5(레몬법 대상 가능·주의)는 **메시지가 아니라 고객 이력**을 본다. 시연 차주 8명은 VOC 시연용 데이터라 전원이 하나 이상 걸린다(PRD §20-8 X5·X6 "조건 맞는 차주 없음").
2. **AI가 끝낼 수 있는 길이 고장 위키 하나뿐이다.** 정기점검·수리 진행·보증·차량 정보 같은 **정보 조회형 질문**을 처리하는 경로가 없어 `NO_MATCH`(AI 접수 → VOC 생성·상담원 배정)로 빠지고, 유형도 기본값 '품질 결함'이 된다.

## 3. 판정 순서 (새 흐름)
```
차주 메시지
 0) 주입 시도(관리자 모드·다른 고객…)            → 거절 (지금과 같음)
 1) 즉시 연결  R1 안전 키워드                     → HANDOFF (+팀장)
              R6 강한 불만 / R8 화남(감정 표현)
              R9 사람 요청("상담사", "통화", "직원")
 2) 정보 조회  I1 정기점검 · I2 수리 진행 · I3 보증 · I4 차량 정보 · I5 내 VOC 상태
              → INFO: Apex가 데이터로 답을 만든다. 이력 규칙 R2~R5 적용 안 함
              → 데이터가 비어 답할 수 없으면 → HANDOFF(사유 "AI 답변 불가: 데이터 없음")
 3) 문제 문의  위키 매칭 + 이력 규칙 R2~R5·R7     → 지금과 같음 (GUIDE / HANDOFF)
 4) 어디에도 안 맞음                              → NO_MATCH(AI 접수 → 상담원 배정, 지금과 같음)
```
- 한 문장에 정보 조회와 문제가 섞이면("수리 맡겼는데 아직도 안 끝나서 화나요") **1)이 먼저** → 연결.
- 정보 조회 의도가 둘 이상이면 키워드가 먼저 나온 것 하나만 답하고 "다른 것도 궁금하시면 이어서 물어봐 주세요".
- R2~R5는 정보 조회일 때 **연결 사유가 아니라 '상담원 참고'**로 판단 근거 패널에만 표시한다.

- 위 답변 예의 날짜·km·담당자는 **문장 모양을 보여 주는 예시**다(VEH-0003 하자 수리 입고 10/14만 org 실제 값). 실제 값은 구현 때 org 데이터로 확인.
- **본인 차량·본인 VOC만** 조회(본인 확인된 contactId·vehicleId 기준). 다른 고객 정보는 지금처럼 거절.
- 보상 금액 약속·레몬법 확답·종결 판단은 하지 않음(§20-1 가드레일 유지). 레몬법 질문은 정보 조회에 넣지 않고 사람에게.
- 문장을 Apex가 만드는 이유: 숫자·날짜가 틀리면 안 되는 답이고, AI 호출을 줄인다. 말투만 다듬고 싶으면 v4.4에서 Prompt로(결정 D2).

## 6. 대화 흐름 (LWC)
```
ASK → INFO 답변 → [빠른 답] "궁금증 해결됐어요" / "상담사 연결해 주세요" / 이어서 질문 입력
       ├ 해결됐어요 → 별점 → 기록(결정 D3) → END
       ├ 상담사 연결 → HANDOFF(사유 R9 사람 요청) → END
       └ 이어서 질문 → ASK로 다시 (같은 세션에서 여러 번)
```
- 지금은 판정 한 번이면 END → **정보 조회는 대화가 이어지도록** 바꾼다.
- 오른쪽 '판단 근거' 패널: 의도(I1~I5)·사용한 데이터·이력 규칙 '상담원 참고' 표시.
