# 오로라 오너스 360 브랜드 가이드 (v3.5)

> 가상 브랜드 **오로라모터스 AURORA**의 오로라 오너스 360 앱 디자인 기준. 시안·LWC·3D 모델·탭 아이콘은 모두 이 문서를 따른다.
> 적용 범위는 **오로라 앱 단위 설정, 오로라 전용 페이지·홈·리스트 뷰·LWC**뿐이다. org 테마·실습 앱은 바꾸지 않는다(PRD §18-2).
> 실제 자동차 브랜드 로고·이미지·CAD는 쓰지 않는다. 로고·아이콘·일러스트·3D 모델은 모두 직접 만든다.

| 파일 | 용도 |

- 여백: 심볼 높이의 1/4 이상 비운다. 최소 크기: 심볼 24px, 워드마크 높이 32px.
- 금지: 심볼 색 바꾸기, 곡선 개수 바꾸기, 늘이거나 기울이기, 사진 위에 올리기, 실제 자동차 엠블럼과 합치기.
- Salesforce 앱 로고에는 심볼 PNG(정사각형)를 쓴다. SVG는 원본으로 저장소에 둔다.

## 3. 글자

- Salesforce 화면: SLDS 기본 글꼴(Salesforce Sans) 그대로. LWC에서 글꼴을 바꾸지 않는다.
- 시안 HTML: `'Segoe UI', 'Apple SD Gothic Neo', 'Noto Sans KR', Arial, sans-serif` (외부 웹폰트 없음).
- 크기: 카드 제목 16px 굵게 / 핵심 숫자 28px 굵게 / 본문 13px / 라벨·배지 12px.
- 숫자는 천 단위 쉼표, 금액은 "원", 시간은 "1시간 20분 남음"처럼 사람 말로.

## 4. 배지 문구 규칙

형식: `[아이콘] 명사구` 또는 `[아이콘] 명사구 · 값`. 8글자 안팎, 동사·문장부호 없이.

| 상태 | 문구 예 | 색 | 아이콘 |
|---|---|---|---|
| 안전 결함 | `⚠ 안전 결함` | 위험 | `utility:warning` |
| 기한 초과 | `⏱ 기한 초과 · 2시간` | 위험 | `utility:clock` |
| 기한 임박 | `⏱ 기한 임박 · 1시간 20분` | 주의 | `utility:clock` |
| 기한 준수 | `✓ 기한 준수` | 정상 | `utility:success` |
| 이관 요청 | `↑ 팀장 이관 · 정원이` | 주의 | `utility:arrowup` |
| 보증 내 | `🛡 보증 내 · 배터리` | 정상 | `utility:shield` |
| 보증 만료 | `🛡 보증 만료 · 일반` | 종결 | `utility:shield` |
| 미승인 보상 | `₩ 승인 대기 · 1건` | 주의 | `utility:moneybag` |
| 레몬법 | `⚖ 레몬법 대상 가능` / `⚖ 레몬법 주의` | 위험 / 주의 | `utility:law` |
| 반복 결함 | `↻ 반복 결함 · 제동` | 주의 | `utility:refresh` |
| 종결 | `● 종결` | 종결 | `utility:check` |

- 배지는 한 줄에 **위험 → 주의 → 정상 → 정보 → 종결** 순서로 놓는다. 가장 급한 것이 왼쪽.
- 리스트 뷰는 LWC를 못 넣으므로 수식 텍스트 필드 "상태 표시"에 같은 문구를 기호와 함께 쓴다(예: `● 안전 결함 · 기한 초과`). 색은 없고 글자만 있다(PRD §18-4 #2).
- 위 `utility:*` 이름은 SLDS 아이콘이다. 구현 Step(S5)에서 존재를 확인하고, 없으면 가장 가까운 아이콘으로 바꿔 이 표를 고친다.

## 6. 레이아웃 원칙 — "3초 규칙"

상담원이 화면을 열고 3초 안에 **무슨 일인지, 얼마나 급한지, 누가 처리하는지** 알 수 있어야 한다.

1. **맨 위 상황 카드**: 번호·제목·차주·차량 / 상태 단계 / 남은 기한 / 현재 처리 직원·팀장. 위험도에 따라 카드 왼쪽 테두리 색(빨강·주황·초록).
2. **바로 아래 상태 배지 줄**: 4장 규칙. 해당하는 배지만 표시하고, 없으면 `✓ 특이 사항 없음` 하나.
3. **본문은 탭**: VOC = [처리] [차량·보증] [보상] [이력] [3D] [상세]. 첫 탭 [처리]에 지금 단계에서 할 일만.
4. **필드 순서는 업무 순서**: 접수 → 확인 → 조치 → 종결. 사람이 입력하는 필드가 먼저, **자동 계산 필드는 한 섹션에 모아** 회색 배경과 `자동 계산` 머리말로 구분.
5. **조건부 표시**: 안전 결함일 때만 "안전 결함 대응" 섹션, 이관 요청일 때만 이관 정보 강조, 보상이 없으면 보상 영역을 접음.
6. 한 화면 첫 영역(스크롤 전)에 입력 필드 8개 이하.

### 페이지별 순서
| 페이지 | 위에서부터 |
|---|---|
| 오로라 홈 | 브랜드 히어로(진행 중·기한 임박·이관 대기·안전 결함 숫자) → 빠른 VOC 접수 → 업무 카드 3 → 차트 3 |
| VOC | 상황 카드 → 배지 줄 → Path → 탭 |
| 차주(연락처) | 차주 360 카드(이니셜 아바타·등급·위험 등급·최근 90일 VOC 수) → 보유 차량 카드 → VOC 이력 → 타임라인 |
| 고객 차량 | 차량 카드(차종 일러스트·번호판·주행거리) → 보증 게이지 → 품질 신호(레몬법·반복 결함) → 3D → 이력 |

## 8. 접근성

- 글자/배경 대비 4.5:1 이상(2-3 표 계산값).
- 색만으로 구분하지 않는다: 배지·핀·차트 범례에 항상 글자.
- 깜빡임은 초당 3회 미만(1초 주기).
- 3D 화면 옆에는 같은 정보를 담은 **부품 목록(글자)**을 함께 둔다(화면 낭독기·저사양 PC 대비).
- 버튼에는 글자 라벨(`분해`, `조립`, `처음 시점`)을 쓴다.
